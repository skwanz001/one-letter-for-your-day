One letter for one day: **D**.

D stands for "doomscrolling" — the word for today: hours lost thumbing
through disaster news in bed, phone glow at 2am, every refresh worse
than the last. Vivid, funny, and (sadly) true.

`main.py` (Python 3.13, standard library only) writes exactly that one
letter, and nothing else, to `/output/entry.txt` — a single byte, no
trailing newline, as the gate requires.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
